# Microsoft Intune Administration Labs

## Overview

This repository contains hands-on Microsoft Intune administration labs completed using a Microsoft 365 Developer Tenant and Microsoft Entra ID.

The labs focus on endpoint management, device security, compliance, application deployment, Windows Autopilot, and enterprise administration. Each lab documents the objective, configuration steps, screenshots, and key concepts learned through practical implementation.

# Labs Included

| Lab | Topic | Description |
|------|-------|-------------|
| Lab 01 | Intune Enrollment & Device Configuration Basics | Configured automatic enrollment, Enrollment Status Page (ESP), pilot groups, configuration profiles, enrollment restrictions, and applicability rules. |
| Lab 02 | Compliance Policies & Conditional Access | Created Windows compliance policies and integrated device compliance with Microsoft Entra Conditional Access. |
| Lab 03 | Windows Update Ring Configuration | Configured Windows Update Rings, update deferrals, restart behavior, and deployment deadlines. |
| Lab 04 | Windows Feature Update Policy | Deployed Windows 11 version 24H2 using Feature Update policies with a pilot group. |
| Lab 05 | Endpoint Security Policies | Configured Microsoft Defender Antivirus, Windows Firewall, and BitLocker security policies. |
| Lab 06 | Windows Enrollment Restrictions | Configured Windows enrollment restrictions, device ownership settings, and enrollment assignments. |
| Lab 07 | Windows Autopilot & Enrollment Status Page | Configured Windows Autopilot deployment profiles and Enrollment Status Page (ESP) settings. |
| Lab 08 | Microsoft Store App (New) Deployment | Deployed Adobe Acrobat Reader DC using Microsoft Store app (new) in Microsoft Intune and assigned it to a pilot group. |
